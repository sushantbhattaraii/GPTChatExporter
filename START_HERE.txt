ChatGPT Conversation Exporter 1.5.2

Updating an earlier version: Extract the ZIP and replace the contents of your
previously loaded dist folder with the new dist contents. Click Reload
on the extension card at chrome://extensions/, then refresh your chat.
Verify the popup says v1.5.2.

New installation:
1. Extract this ZIP completely.
2. Open Google Chrome and go to chrome://extensions/
3. Turn on Developer mode.
4. Click Load unpacked.
5. Select the dist folder inside chatgpt-conversation-exporter.
6. Enable/pin the extension and refresh ChatGPT.
7. Use Export this Q&A below a completed response, or the floating download
   arrow for whole-chat export. The gear opens settings.

No Node.js installation is required for the included dist build.

README.md contains the full guide, settings, privacy and limitations.
TESTING.md separates executed tests from live checks still required.

PDF typesets equations. Word includes editable equations. Images are embedded when readable.
PDF preserves visible syntax colors, whitespace and paragraph alignment.
Prompts are right-aligned. Responses use the full page text width under navy headings.
Both print directly on the page. See examples/transcript-layout.pdf.
If an external image needs access, open the extension popup and choose
Allow images and continue. Approve only the listed sites you want to include.
The ongoing export resumes. Long history scans continue while they make progress.
Code longer than its scroll pane continues across PDF pages. See examples/scrollable-code.pdf.
See examples/thumbnail-layout.pdf for thumbnail sizes, search rows and cropped images.
See examples/career-components.pdf for company links, a career diagram and a job card.
See examples/formatted-chat.pdf for typography and examples/rich-content.pdf
for diagrams, checklist states, multilingual text and static widget output.
Live signed-in ChatGPT, real Chrome downloads and Microsoft Word need the
local smoke test. The interface can change; permanent compatibility is not guaranteed.
