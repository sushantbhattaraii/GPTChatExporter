ChatGPT Conversation Exporter 1.0.1

Updating from 1.0.0: Extract the ZIP and replace the contents of your
previously loaded dist folder with the new dist contents. Click Reload
on the extension card at chrome://extensions/, then refresh your chat.
Verify the popup says v1.0.1.

New installation:
1. Extract this ZIP completely.
2. Open Google Chrome and go to chrome://extensions/
3. Turn on Developer mode.
4. Click Load unpacked.
5. Select the dist folder inside chatgpt-conversation-exporter.
6. Enable/pin the extension and refresh ChatGPT.
7. Use Export this Q&A below a completed response, or Export conversation.

No Node.js installation is required for the included dist build.

README.md contains the full guide, settings, privacy and limitations.
TESTING.md separates executed tests from live checks still required.

Important: equations export as LaTeX text; images use text descriptions.
Live signed-in ChatGPT, real Chrome downloads and Microsoft Word need the
local smoke test. The interface can change; permanent compatibility is not guaranteed.
